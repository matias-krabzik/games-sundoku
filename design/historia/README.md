# Historia — reservada para SunDoku 2.0

Decisión del 19 de septiembre de 2026: publicar primero el juego simple, con el objetivo de lanzarlo antes de terminar septiembre. La historia queda fuera de la versión 1.0.

Se conservan aquí el guion, la progresión y el plan como referencias para 2.0. Las listas marcadas como completadas en los documentos históricos corresponden al prototipo retirado, no a funcionalidades de la versión actual.

`prototipo-2.0/` contiene el catálogo, modelos, controlador, pantalla y pruebas de las escenas como archivos `.dart.txt`. No se compilan ni se ejecutan. Para retomarlo habrá que volver a integrar victoria, navegación y guardado sobre la versión vigente del juego.

La versión actual mantiene el tutorial original, el acceso directo desde cada celebración al siguiente sudoku y la salida al mapa o siguiente nivel. Los módulos de historia que ya existan en un guardado quedan inactivos; el progreso de los sudokus se conserva. Se mantiene la corrección de coordenadas locales en las animaciones del tablero.
