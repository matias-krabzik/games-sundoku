# Doku: primeras referencias 3D

Generadas con la herramienta integrada de imágenes a partir de `assets/images/doku-home.png`. Son bocetos de referencia, no un modelo 3D ni recursos para integrar al juego.

- `front.png`: frontal en pose A.
- `side.png`: vista lateral aproximada; todavía presenta perspectiva y necesita ajuste para una referencia ortográfica estricta.
- `back.png`: propuesta de espalda, inferida a partir del diseño frontal.

La verificación detectó imágenes RGB con cuadros dibujados: **no tienen transparencia real**, incluso después de un intento de extracción. Falta resolver el fondo antes de considerarlas entregables finales. No se modificó el arte del juego.
