# Propuesta de menú para más adelante

`gamification-menu-concept.png` es una referencia visual aprobada para guardar,
no un recurso listo para integrar ni un cambio implementado.

- Doku mediano, con más espacio para el menú y el progreso.
- Dos tarjetas ilustradas: Aventura y Partida rápida.
- Propuesta de reto diario, racha de días y recompensas.
- Valores ilustrativos; conservar el paisaje de la home al implementar.

La cuadrícula de la imagen no forma parte del diseño. Para implementar, reutilizar
los recursos existentes y componer widgets y texto reales con elementos separados.
